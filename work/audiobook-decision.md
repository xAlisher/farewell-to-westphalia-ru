# Аудиокнига: выбор TTS-движка (пилот 2026-08-19)

**Решение: edge-tts, голос `ru-RU-DmitryNeural`.** Генерация аудиокниги пока НЕ запускалась —
зафиксирован только выбор движка по результатам пилота.

## Пилот

Один и тот же текст — начало главы 1 (~5 100 знаков, 10 абзацев, markdown/сноски вычищены) —
озвучен тремя движками на Sneg (RTX 3090). Сэмплы: `~/Downloads/ftw-ch01-*.mp3` на wild.

| Движок | Голос | Скорость | Заметки |
|---|---|---|---|
| XTTS v2 (форк `coqui-tts`) | Damien Black | RTF 0.22 → вся книга ≈ 40 мин GPU | самый «начитанный» тембр, клонирование голоса; лицензия весов CPML — только некоммерческое |
| Silero v4 ru | eugene | 4,5 мин аудио за 11 с (CPU) | автопростановка ударений (`put_accent`) — меньше всего ошибок ударений; тембр ровнее/суше |
| **edge-tts** | **ru-RU-DmitryNeural** | облако, GPU не нужен | **победитель по звучанию**; неофициальный API Microsoft — серая зона для публикации, объёмных гарантий нет |

## Технические заметки (чтобы не переоткрывать)

- Окружение на Sneg: `~/xtts-env` (Python 3.12, torch 2.5.1+cu121, `coqui-tts` +
  **`transformers==4.57.1`** — версии 5.x и <4.53 ломают импорт TTS), `edge-tts`, `omegaconf` для Silero.
- Скрипты пилота: `~/xtts_pilot.py`, `~/silero_pilot.py` на Sneg (чанки ≤240/800 зн., склейка с паузами 0.3–0.35 с).
- XTTS: первая загрузка модели требует `COQUI_TOS_AGREED=1`.
- GPU Sneg занят `llama-server.service` (Qwen, ~19 ГБ VRAM) — останавливать на время генерации
  (`sudo systemctl stop llama-server.service`), потом вернуть.
- Вход для полной генерации готовится `audiobook_pass.py` (нормализация под диктора:
  числа словами, ударения, сноски, заголовки) — раскатать на все 20 глав перед генерацией.

## Открытые вопросы перед полной генерацией

1. edge-tts — неофициальный API: объём ~10–11 ч аудио за один прогон может упереться в лимиты;
   план Б — Silero (стабильность) или XTTS (тембр) локально на Sneg.
2. Пройтись по правам: голос Microsoft для публично раздаваемой аудиокниги на сайте
   (условия использования голосов Azure/Edge).
3. Смешанный EN-текст (библиография, цитаты) — `audiobook_pass.py` уже уплощает; проверить на главе 19.
