# Решение №49 — перевод термина "human governance"

- **Issue:** [#49](https://github.com/xAlisher/farewell-to-westphalia-ru/issues/49) (дубликат: [#43](https://github.com/xAlisher/farewell-to-westphalia-ru/issues/43), подан до v2)
- **Дата решения:** 2026-08-20
- **Статус:** ПРИНЯТО (с уточнением) · реализация — отдельным PR
- **Чанк-триггер:** `01-001`; фактический охват — весь корпус

## Претензия (из issue)

Текущий вариант «человеческое управление»: (1) коллизия с «человечный» → читается как
*humane management*; (2) коллизия с «управление людьми» → читается как HR. В оригинале
модификатор задаёт *домен* (управление человеческими делами — в противовес управлению
денежными потоками или протоколами).

## Исследование (шаг 0 конвейера: держит ли претензия реальность языка)

1. **Коллизия с HR — подтверждается.** В реальном употреблении сочетание «человеческ* +
   управлен*» почти полностью занято доменом HR: «управление человеческими ресурсами» —
   устойчивый термин ([пример учебника](http://hi-edu.ru/e-books/xbook962/01/part-002.htm),
   [энциклопедия](http://encyklopediaap.uw.edu.pl/index.php/УПРАВЛЕНИЕ_ЧЕЛОВЕЧЕСКИМИ_РЕСУРСАМИ)).
   Словарные корпуса ([Reverso](https://context.reverso.net/translation/english-russian/Governance),
   [Linguee](https://www.linguee.ru/английский-русский/перевод/governance.html)) не фиксируют
   «человеческое управление» как передачу governance.
2. **Предлагаемая форма соответствует регистру аудитории.** Русскоязычная крипто/DAO-литература
   естественно пишет «сообщество управляет», «управление сообществом»
   ([Википедия/ДАО](https://ru.wikipedia.org/wiki/Децентрализованная_автономная_организация),
   [Forklog](https://forklog.com/exclusive/detsentralizovannoe-mnogoobrazie-dlya-chego-lyudi-sozdayut-dao)).
3. **Прецедент канонического перевода.** Русское издание Остром *Governing the Commons* —
   «[Управляя общим](https://sotsium.ru/ekonomicheskaya-istoriya/upravlyaya-obshim.html)»
   (ИРИСЭН/Мысль, 2010) — передаёт governance через называние **объекта** управления
   («общим», «институты коллективной деятельности»), а не через прилагательное.
4. Корпус перевода уже непоследователен: 1 вхождение «управления человеческими сообществами»
   против 54 вхождений «человеческ* управлен*» (5 падежных форм, 38 файлов, 12 глав).

## Решение

- **Первое/определяющее упоминание:** «управление человеческими сообществами».
- **Повторные упоминания:** «управление сообществами» или голое «управление» — по контексту
  (стайлгайд и так это предписывает после первого определения).
- «Человеческий» вне коллокации с «управление» («человеческая деятельность» и т.п.) — не трогать.
- Глоссарий: `human governance` → ru: «управление человеческими сообществами»;
  «человеческое управление» добавить в `forbidden_variants`.
- Хвост issue про «управление… управляют» в определении: оригинал дублирует так же
  (governance/manage) — оставить авторский повтор; НЕ принимается.

## Реализация (план)

Полоса «терминология» конвейера: глоссарий → агентный проход по 38 файлам `work/ru-parts/`
(падежи, контекст первое/повторное) → выборочная перепроверка судьёй → пересборка/синк/сборка
сайта затронутых 12 глав (+ заголовок гл. 6, summaries, README при касании) → один PR
`fix/term-human-governance`, closes #49, #43.
